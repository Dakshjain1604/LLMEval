## 💰 Cost Estimate

### AWS Costs (Monthly)

| Service | Usage | Cost |
|---------|-------|------|
| Lambda | 60 executions × 10 min × 2GB | $1.50 |
| S3 | ~110MB storage | $0.50 |
| CloudWatch Logs | ~500MB | $0.50 |
| EventBridge | 60 scheduled events | $0.00 |
| ECR | Image storage | $0.10 |
| **AWS Total** | | **~$2.60** |
| LLM API (OpenRouter) | ~120 calls/month | $2-5 |
| **Grand Total** | | **$4.60-7.60** |

### Cost Optimization Tips

1. **Reduce executions:** Change to once per day instead of twice
2. **Reduce memory:** Use 1024MB if runs complete successfully
3. **Reduce log retention:** Change from 14 days to 7 days
4. **Use cheaper LLM:** Switch to DeepSeek R1 (cheaper) from Sonnet

## 📈 Monitoring

### View Logs

```bash
# Real-time logs
aws logs tail /aws/lambda/llmeval-monitor --follow

# Last hour
aws logs tail /aws/lambda/llmeval-monitor --since 1h

# Specific time range
aws logs tail /aws/lambda/llmeval-monitor \
    --start-time 2024-01-01T00:00:00Z \
    --end-time 2024-01-01T23:59:59Z
```

### Check Database in S3

```bash
# Get account ID
AWS_ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)

# List bucket contents
aws s3 ls s3://llmeval-database-${AWS_ACCOUNT_ID}/

# Download database
aws s3 cp s3://llmeval-database-${AWS_ACCOUNT_ID}/releases.db ./

# View with sqlite3
sqlite3 releases.db "SELECT COUNT(*) FROM releases;"
```

### CloudWatch Metrics

```bash
# Invocation count (last 7 days)
aws cloudwatch get-metric-statistics \
    --namespace AWS/Lambda \
    --metric-name Invocations \
    --dimensions Name=FunctionName,Value=llmeval-monitor \
    --start-time $(date -u -d '7 days ago' +%Y-%m-%dT%H:%M:%S) \
    --end-time $(date -u +%Y-%m-%dT%H:%M:%S) \
    --period 86400 \
    --statistics Sum

# Average duration
aws cloudwatch get-metric-statistics \
    --namespace AWS/Lambda \
    --metric-name Duration \
    --dimensions Name=FunctionName,Value=llmeval-monitor \
    --start-time $(date -u -d '7 days ago' +%Y-%m-%dT%H:%M:%S) \
    --end-time $(date -u +%Y-%m-%dT%H:%M:%S) \
    --period 86400 \
    --statistics Average
```

## 🔄 Update Deployment

### Update Code

```bash
cd lambda-deploy

# Rebuild image
docker build -t llmeval:latest .

# Get variables
AWS_ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
AWS_REGION=$(aws configure get region)

# Push to ECR
docker tag llmeval:latest ${AWS_ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com/llmeval:latest
docker push ${AWS_ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com/llmeval:latest

# Update function
aws lambda update-function-code \
    --function-name llmeval-monitor \
    --image-uri ${AWS_ACCOUNT_ID}.dkr.ecr.${AWS_REGION}.amazonaws.com/llmeval:latest
```

### Update Configuration

```bash
sam deploy --template-file template.yaml --stack-name llmeval-stack
```

## 🆘 Troubleshooting

### Common Issues

**Issue: "Unable to locate credentials"**
```bash
aws configure
# Enter your AWS credentials
```

**Issue: "Docker daemon not running"**
```bash
sudo systemctl start docker
sudo systemctl enable docker
```

**Issue: "Lambda timeout after 15 minutes"**
- Reduce `max_items_per_run` in config
- Increase memory to 3008 MB
- Consider EC2 deployment instead

**Issue: "Database not persisting"**
- Check S3 bucket exists
- Check Lambda has S3 permissions
- View logs: `aws logs tail /aws/lambda/llmeval-monitor`

**Issue: "Function errors"**
- Check CloudWatch logs
- Verify all environment variables set
- Test locally first with `test_local.py`
